# BMI Calculator Using Python

Aplikasi BMI (Body Mass Index) Calculator berbasis desktop yang dikembangkan menggunakan Python, Tkinter, dan CustomTkinter. Aplikasi ini digunakan untuk menghitung nilai BMI berdasarkan tinggi dan berat badan serta menampilkan kategori BMI.

## Features

- Menghitung nilai BMI berdasarkan tinggi dan berat badan.
- Menampilkan hasil perhitungan BMI.
- Menampilkan kategori BMI berdasarkan hasil perhitungan.
- Memberikan warna berbeda untuk setiap kategori BMI.
- Fitur Clear untuk menghapus input dan hasil perhitungan.

## BMI Categories

| Category | BMI Range |
|---|---|
| Underweight | Below 18.5 |
| Normal | 18.5 – 24.9 |
| Overweight | 25.0 – 29.9 |
| Obese | 30.0 – 34.9 |
| Extreme Obese | 35.0 and above |

## Technologies Used

- Python
- Tkinter
- CustomTkinter
- Pillow (PIL)

## Installation and Usage

1. Clone this repository:

```bash
git clone https://github.com/marsaardita/BMI-Calculator-Python.git
```

2. Navigate to the project directory:

```bash
cd BMI-Calculator-Python
```

3. Install the required libraries:

```bash
pip install customtkinter pillow
```

4. Run the application:

```bash
python bmi.py
```
